# 检索相关性：人工盲评与 LLM 判定的一致性

样本：LLM 判定中按 2 / 1 / 0 分各抽 10 条、打乱顺序后由作者盲评（共 30 条，评分时未看 LLM 分数）。

分数分布（0 / 1 / 2）：人工 [15, 11, 4]，LLM [10, 10, 10]。

| 指标 | 主结果（原始盲评） | 敏感性分析（事后） |
|---|---:|---:|
| 完全一致 | 20/30 | 23/30 |
| 相差不超过 1 分 | 29/30 | 29/30 |
| 未加权 Cohen κ | 0.5 | 0.65 |
| 二次加权 κ | 0.667 | 0.722 |
| Spearman ρ | 0.764 | 0.791 |
| ≥1 分（至少相关）二分类一致 | 25/30 | 28/30 |
| =2 分（可直接修复）二分类一致 | 24/30 | 24/30 |

不一致 10 条，其中人工分高于 LLM 的 0 条、低于 LLM 的 10 条（LLM 判定偏宽松）：7（人工 1 / LLM 2）、8（人工 1 / LLM 2）、10（人工 0 / LLM 1）、12（人工 1 / LLM 2）、13（人工 0 / LLM 1）、17（人工 0 / LLM 2）、20（人工 0 / LLM 1）、21（人工 1 / LLM 2）、25（人工 1 / LLM 2）、29（人工 0 / LLM 1）。

=2 分：LLM 判了 10 条，人工只给了 4 条，因此 hit@3 的绝对值应视为偏高的估计；各检索器由同一 LLM 判定，相互比较不受此影响。

敏感性分析：评分细则「1 = 主题相关但不能单独给出修复」若包括「只提到同一异常或类型」，第 13、20、29 条由 0 改为 1。该读法在看过 LLM 分数后才提出，只作补充，不作主结果。
