# 第 0 轮编译错误分类：人工盲评说明（给打分的作者）

## 要做什么

打开 `results/classifier_check/classifier_check.csv`，共 60 条第 0 轮编译错误（cjc 输出，含出错的源码行）。
对每一条，在 `human_category` 列填一个类别名（只能填下面 5 个英文名之一），有疑问可在 `note` 列写一句话。

**打分完成之前不要打开 `classifier_check_key.csv`**（里面是分类器给出的类别）。

## 类别（按「修复这次编译失败的根本原因」判断）

| 填写 | 含义 | 典型例子 |
|---|---|---|
| `foreign_syntax` | 写成了其他语言的语法，仓颉无法解析 | `for (let i in 0 until n)`、`val x = …`、`x => x + 1` 形式的 lambda、`if (c) return x`（缺花括号）、`\(name)` 字符串插值 |
| `api_or_undeclared` | 调用或导入了不存在、不可访问的函数 / 成员 / 类型，或忘了导入包 | `xs.length()`（实为 `size`）、`toInt64()` 未声明、`ArrayList` 未导入、`import std.math.{max}`（该包没有导出 `max`） |
| `type_or_mutability` | 语法和名字都对，但类型不匹配、给不可变变量赋值、运算符或重载不适用 | `let` 变量被重新赋值、`UInt8` 与 `String` 比较、函数参数类型不符 |
| `duplicate_main` | 重复定义 `main` 或同名函数重载冲突 | `multiple 'main'` |
| `other_compile` | 不属于以上任何一类 | 泛型参数无法推断、访问权限、非静态成员按类型名访问等 |

## 判断规则

1. 一条里有多个报错时，按**第一个报错**的根本原因判断；
2. 报错文字和根本原因不一致时，以根本原因为准（例如报 `expected ';'`，但实际原因是用了 `val`，记 `foreign_syntax`）；
3. 实在无法判断时记 `other_compile`，并在 `note` 写明原因。

填完后保存（保持 UTF-8 编码），告诉 Junjie 运行 `python src/classifier_check.py` 计算一致率。
