## 〇、写作前必读

- 补充实验回应的是**模拟审稿**，论文尚未投稿。不要写成「应审稿人要求补充」；按时间顺序如实交代：
  第 3 阶段与 Original-30 在前，扩展矩阵（`results/review/`）的统计方案在看到其结果之前写定。
- 「显著」一律指**族内 Holm 校正后 p < 0.05**。三个族：G（推广到其他模型，186 个比较）、A（Agent 基线，107 个）、
  R（改进检索 rag2，53 个）；交互效应单独一族 I（验证性 21 个，另有探索性 I-explore 9 个）。
- p 值用 10,000 次符号翻转置换，最小只能到约 1e-4；所以族 G 里显著的比较 Holm 后都是 0.0186、族 A 是 0.0107。
  这只是置换次数的下限，不代表各比较的强度相同——比较强弱请看差值和 95% CI。
- 差值单位是百分点：每道题先取 3 次重复的平均通过率，再对两组求差，最后对题求平均。

## 二、主要结论

### 结论 1：把真实的编译器报错反馈给模型（raw vs blind）是最主要、最普遍的收益
- 族 G 中 raw vs blind 共 43 个比较，**20 个显著，全部为正**，没有一个为负。
- ClassEval 上最明显：15 个比较全部为正，平均 +23.3 个百分点（范围 +14.7 ~ +42.9）；
  HumanEval 平均 +6.7、Original-30 平均 +7.8（这两个数据集很多模型 R5 已接近 100%，见第四节「天花板」）。
- 最大的几个：GLM ClassEval direct +42.9 [33.7, 52.4]；U2-Flash ClassEval direct +36.1；Doubao-2.1-lite HumanEval direct +33.5。
- 第 3 阶段与 Original-30 方向一致（stage3：DeepSeek ClassEval direct +25.4，Doubao-mini HumanEval direct +21.8、syntax +15.9；
  Original-30：Doubao-mini syntax +31.1）。

### 结论 2：在报错之外再加规则提示（hint）或检索文档（rag），只对弱模型有帮助
- 族 G：hint vs raw 43 个比较中显著 2 个；rag vs raw 显著 1 个；rag vs hint 显著 0 个。
- 显著的都来自 **Doubao-Seed-2.1-lite**：hint vs raw ClassEval direct +13.5、HumanEval direct +9.8；rag vs raw HumanEval direct +7.7。
  第 3 阶段中同样只有较弱的 Doubao-mini 显著（hint vs raw HumanEval direct +15.9；rag vs raw +7.9 ~ +13.8）。
- 其他模型的 hint vs raw、rag vs raw、rag vs hint 差值绝对值都不超过 4 个百分点，没有一个经 Holm 校正后显著
  （未校正时只有 MiniMax HumanEval direct rag vs raw +2.0 [0.6, 3.7] 的 CI 不含 0）。
- 写法建议：「提示与检索的增益随模型能力增强而消失」，而不是「提示 / 检索无效」。

### 结论 3：语法参考手册（syntax 起点）可以替代规则提示——验证性检验在 Doubao-2.1-lite 上成立
- 交互 I = (hint − raw)<sub>direct</sub> − (hint − raw)<sub>syntax</sub>，I > 0 表示有手册时 hint 的增益变小。
- 验证性族 I（统计前未看过）：**Doubao-2.1-lite ClassEval +13.1 [6.8, 19.8]，p(Holm) = 0.01；HumanEval +8.9 [5.3, 13.0]，p(Holm) = 0.002**；
  Original-30 +16.7，方向相同但不显著（只有 30 题）。其余模型 I 都接近 0——它们在 direct 起点上 hint 本来就没有增益，谈不上替代。
- 探索性（数据此前已看过）：Doubao-mini HumanEval +14.6，p(Holm) < 0.001，方向一致；只能作旁证，不能作验证性结论。
- 描述性（未做检验）：syntax 起点普遍大幅提高第 0 轮通过率（如 Doubao-2.1-lite HumanEval 27.4% → 79.3%，
  GLM HumanEval 59.1% → 92.7%）。

### 结论 4：让模型自己决定何时检索（Agent）并不比每轮固定检索好
- 族 A agent vs rag（同样最多 5 次模型调用）：54 个比较中显著 2 个，**都为负**（Agent 更差）：
  Doubao-2.1-lite HumanEval direct −9.6、Doubao-mini HumanEval direct −10.4；没有一个显著为正。
  平均差值：ClassEval −2.6、HumanEval −2.0、Original-30 −2.2。
- 可能的解释（描述性）：Agent 很少主动检索——5 步预算下平均每题检索 0.29 次，至少检索一次的题平均约占 15%。

### 结论 5：放宽 Agent 的步数（15 步 vs 5 步）有稳定收益，主要在 ClassEval
- 族 A agent15 vs agent：53 个比较中**显著 14 个，全部为正**；ClassEval 17 个比较全部为正，平均 +10.0 个百分点。
- 最大的：Doubao-mini Original-30 direct +31.1、Doubao-2.1-lite ClassEval direct +25.8、Doubao-mini HumanEval direct +23.2。
- 注意：agent15 最多用 15 次模型调用，是 agent 的 3 倍，这是「多花预算换通过率」，不是同等预算下的比较；
  写的时候要和成本一起说。其中两个比较处在显著边界，见第三节。

### 结论 6：改进检索（rag2：先改写查询再检索）没有带来可检测的收益
- 族 R rag2 vs rag：53 个比较，**显著 0 个**；平均差值 ClassEval −0.3、HumanEval −0.1、Original-30 +0.4。
- rag2 还多了查询改写调用的成本（已按改写模型单价计入）。这是一个可报告的阴性结果。

### 结论 7：成本差异很大，贵的模型不一定划算
- 「每解一题美元成本（含共享第 0 轮）」，以 ClassEval direct raw 为例：GPT-6-Luna $0.008、Claude-Haiku-5.5 $0.013、
  U2-Flash $0.028、MiniMax $0.047、GLM $0.114、Kimi-K3.1-Pro $0.416。
  Kimi 通过率最高（R5 77.4%），但单题成本约为 GPT-6-Luna（59.5%）的 50 倍。
- 完整数字见 `review_stats.md` 的「各配置通过率与成本」表。

## 三、稳健性（可直接引用）

- 去掉判定不稳定的题（HumanEval 第 20 题、ClassEval 第 58 题）和每个比较中任一组超时的题后重算：
  第 3 阶段 33 个比较、Original-30 17 个比较的结论**全部不变**；补充实验 346 个比较中 Holm 显著数 **40 → 40**，差值最大变化 3.55 个百分点。
- 结论改变的 5 个比较：
  - 2 个处在显著边界（都属于结论 5）：DeepSeek ClassEval direct agent15 vs agent（p(Holm) 0.038 → 0.073）；
    U2-Flash ClassEval syntax agent15 vs agent（0.055 → 0.046）。写作时应说明这两个比较「接近边界、对超时题敏感」。
  - 3 个是 GLM 的差值在 0 附近变号，前后都远不显著（p(Holm) = 1.0），不影响任何结论。
- 三族合并成一个族做 Holm 的结果也在 `review_stats.md` 中（「p(Holm，三族合并)」一列）。

## 四、局限与必须交代的事项

1. **天花板效应**：HumanEval 和 Original-30 上很多模型 R5 达到或接近 100%；hint vs raw、rag vs raw、rag vs hint
   各有 13/43 个比较两组在每道题上完全相同。这些数据集上的「无差异」部分是因为没有提升空间，结论应以 ClassEval 为主。
2. **GLM-5.3-Flash 的超时**：ClassEval 上单次输出极长，超时题按未通过计入（方案第八节），共 52 题次；
   敏感性分析去掉后结论不变。GLM ClassEval syntax rag2 一格缺失。
3. **GLM ClassEval syntax 的第 0 轮分裂**（方案第九节）：agent15 三组用的第 0 轮与同格其他组不同，未做 agent15 vs agent 配对；
   该格其余比较共享同一份第 0 轮。
4. **温度与渠道**：Kimi 受 API 限制用 temperature = 1.0，其余模型 0.3；部分模型中途换过 API 渠道或 key（同一模型），
   详见 `docs/实验偏离记录.md`。第 3 阶段的旧 Kimi 数据（4 组）不与补充实验的 Kimi 合并。
5. **ClassEval 第 48 题**：参考答案本身在本地编译失败；部分组的第 0 轮判定在重复评测时不一致（Kimi 36 组），
   未加入不稳定题清单，已写入偏离记录。
6. **DeepSeek-V4.1-Flash 与 Doubao-Seed-2.0-mini** 的原有组复用第 3 阶段数据，在族 G 中不重复检验第 3 阶段已比较过的内容；
   它们的交互效应只作探索性结果。
