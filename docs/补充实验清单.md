## 四、正式运行（批次 1–4，可以分几天）

```powershell
python src/run_matrix.py --matrix review -p 2 -j 4 --only "^(glm53f|doubao21l)_(?!.*_rag2_)"
```

- 每批完成后运行同一条命令加 `--check`（例如 `python src/run_matrix.py --matrix review --check --only "^kimik31p_(?!.*_rag2_)"`），把输出贴给我。

## 五、`rag2`（批次 5–6，需要先启动本地检索服务）

`rag2` 每轮先用 Doubao-Seed-2.0-mini 改写查询，再调用本机的检索服务（bge-m3 + 重排模型，占用约 4.5 GB 显存）。

1. 另开一个终端启动检索服务，**整个 `rag2` 运行期间不要关**：
   ```powershell
   .venv-retrieval\Scripts\python.exe src\retrieval_server.py
   ```
   看到 `rag2 检索服务已就绪` 再继续。
2. 先试跑，再正式运行：
   ```powershell
   python src/run_matrix.py --matrix review --pilot -p 2 -j 4 --only "^(?!u2f_).*_rag2_"
   python src/run_matrix.py --matrix review -p 2 -j 4 --only "^(?!u2f_).*_rag2_"
   python src/run_matrix.py --matrix review -p 1 -j 2 --only "^u2f_.*_rag2_"
   ```
3. 若出现大量 `ConnectionRefusedError` / `URLError`，说明检索服务没开或已退出，重启服务后重跑同一条命令即可。
